# Selenium Automation Framework

## Overview
This project is an end-to-end Selenium Automation Framework developed using Java, Selenium WebDriver, TestNG, Maven, and Page Object Model (POM).

The framework automates the checkout flow of the SauceDemo application.

---

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Apache POI (Excel Data-Driven Testing)
- Jenkins
- Git
- GitHub

---

## Features

- Login Automation
- Add Product to Cart
- Checkout Flow
- Data-Driven Testing using Excel
- Screenshot Capture on Test Failure
- Explicit Waits
- Maven Build
- Jenkins Integration
- TestNG Reporting

## How to Run

Clone the repository

```

```

Run using Maven

```
mvn clean test
```

Or run from Jenkins.
